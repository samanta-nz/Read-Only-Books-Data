- **ایمنی و اختیار شنونده:** پیشنهادها اختیاری بیان شوند. شنونده هر زمان خواست می‌تواند چشم‌ها را باز کند، تمرین را متوقف کند یا توجهش را به محیط برگرداند. از ادعای درمان یا تضمین نتیجه استفاده نشود.
